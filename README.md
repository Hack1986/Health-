# My Health Record V8 — GitHub Pages (Offline-first)

แพ็กเกจสำหรับเผยแพร่ผ่าน GitHub Pages และติดตั้งเป็นเว็บแอป (PWA) บน Android/iPhone

## เผยแพร่บน GitHub Pages
1. สร้าง GitHub repository ใหม่
2. แตก ZIP นี้ แล้วอัปโหลด **ไฟล์และโฟลเดอร์ทั้งหมดภายใน** ไปไว้ที่ root ของ repository (ต้องเห็น `index.html` ที่หน้าแรก)
3. ไปที่ **Settings → Pages**
4. ที่ Build and deployment เลือก **Deploy from a branch** → Branch `main` → Folder `/ (root)` → Save
5. รอ GitHub Pages เผยแพร่ แล้วเปิด URL ที่ GitHub แสดงให้ (ต้องใช้ HTTPS)

## ติดตั้งบน Android
1. เปิด URL ด้วย Chrome
2. แตะเมนู ⋮ → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**
3. ยืนยันติดตั้ง แล้วเปิดจากไอคอน My Health Record

## ติดตั้งบน iPhone/iPad
1. เปิด URL ด้วย Safari
2. แตะปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น)
3. เลือก **Add to Home Screen / เพิ่มไปยังหน้าจอโฮม**
4. แตะ Add / เพิ่ม แล้วเปิดจากไอคอน

## การใช้งานออฟไลน์และความเป็นส่วนตัว
- การเปิด URL และติดตั้งครั้งแรกต้องใช้อินเทอร์เน็ต เพราะ GitHub Pages เป็นที่ให้บริการไฟล์เว็บ
- เปิดแอปครั้งแรกโดยยังออนไลน์ รอให้หน้าเว็บโหลดเสร็จ เพื่อให้ Service Worker เก็บไฟล์หลักไว้ในเครื่อง
- จากนั้นทดลองเปิดโหมดเครื่องบินและเปิดแอปจากไอคอนอีกครั้ง
- แอปตั้งค่าให้ทำงานแบบ offline-first: ใช้ไฟล์แอปที่เก็บไว้ในแคช และตัวแอปไม่มีระบบบัญชี, cloud sync หรือส่งข้อมูลสุขภาพไปยังเซิร์ฟเวอร์
- การอัปเดตแอปต้องเชื่อมต่ออินเทอร์เน็ตเพื่อรับไฟล์รุ่นใหม่
- ข้อมูลสุขภาพเก็บในพื้นที่จัดเก็บของเบราว์เซอร์บนอุปกรณ์นี้ ไม่ซิงก์ข้ามอุปกรณ์หรือข้ามเบราว์เซอร์

## สำคัญก่อนใช้จริง
- **อย่าล้าง Site data / Clear storage / ถอนข้อมูลเว็บไซต์** เพราะอาจทำให้ประวัติสุขภาพสูญหาย
- สำรองข้อมูลจากเมนูในแอปเป็นไฟล์ JSON เป็นระยะ และเก็บไฟล์ไว้ในที่ปลอดภัย
- PIN เป็นการล็อกหน้าจอ ไม่ใช่การเข้ารหัสฐานข้อมูลในเบราว์เซอร์; ไฟล์สำรอง JSON ก็ไม่ได้เข้ารหัส
- การเตือนยาในเว็บทำงานได้เมื่อแอปเปิดอยู่เป็นหลัก ไม่รับประกันเมื่อปิดแอปหรือระบบพักเบื้องหลัง
- แจ้งเตือนสุขภาพเป็นการคัดกรองเบื้องต้น ไม่ใช่การวินิจฉัยหรือทดแทนคำแนะนำจากบุคลากรทางการแพทย์

## โครงสร้างไฟล์
- `index.html` — แอป
- `manifest.webmanifest` — ข้อมูลสำหรับติดตั้ง PWA
- `service-worker.js` — แคชไฟล์เพื่อใช้งานออฟไลน์
- `icons/` — ไอคอนแอป


## การตั้งค่าสำหรับ GitHub Pages โปรเจกต์นี้
ไฟล์รุ่นนี้กำหนด manifest, start_url, scope และ Service Worker ให้ตรงกับ `https://hack1986.github.io/My-health-/` โดยตรง เพื่อให้ไอคอนที่ติดตั้งเปิดกลับมาที่หน้าแอปในโฟลเดอร์โปรเจกต์ ไม่ใช่หน้า root ของโดเมน
