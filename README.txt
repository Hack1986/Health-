My Health Record PWA V8 - Offline Edition

รุ่นนี้พัฒนาต่อจาก V7 โดยเน้นใช้งานในอุปกรณ์เครื่องเดียวและออฟไลน์

เพิ่ม/ปรับปรุง 8 เรื่อง:
1. สำรองข้อมูลทั้งหมดเป็นไฟล์ JSON ลงในอุปกรณ์ และกู้คืนจากไฟล์ได้
2. ตั้ง PIN 6 หลักเพื่อกั้นหน้าแอป และล็อกแอปได้เอง
3. แก้ไขและลบรายการสุขภาพย้อนหลังได้
4. ตรวจสอบช่วงตัวเลขก่อนบันทึก และบังคับกรอกความดันบน/ล่างให้ครบคู่
5. คงรายการยา เวลาเตือน และการแจ้งเตือนในเครื่อง (ข้อจำกัด: เว็บอาจไม่เตือนเมื่อปิดแอป/ระบบพักเบื้องหลัง)
6. คงรายงาน PDF พร้อมกราฟและสรุปข้อมูล
7. Service Worker เปลี่ยนเป็น offline-first ใช้ไฟล์ที่แคชไว้ ไม่เรียกเครือข่ายขณะใช้งานปกติหลังติดตั้ง/แคชครบ
8. เพิ่มคำชี้แจงความเป็นส่วนตัว: ไม่มีบัญชีผู้ใช้ ไม่มี cloud sync และไม่มีการส่งข้อมูลสุขภาพออกจากอุปกรณ์โดยตัวแอป

ข้อมูลเดิม:
- ใช้ localStorage keys เดิม เช่น records, profile, medicationItems, limits เพื่อรักษาข้อมูลรุ่นก่อนบนอุปกรณ์และ origin เดิม
- อย่าล้าง Site data / Clear storage และอย่าเปลี่ยน URL/origin หากต้องการเก็บข้อมูลเดิม
- สำรองข้อมูลจากเมนูตั้งค่าก่อนอัปเดตทุกครั้ง

การติดตั้งและออฟไลน์:
- การเปิด URL ครั้งแรกและติดตั้ง PWA ต้องใช้อินเทอร์เน็ต และต้องเปิดแอปอย่างน้อยหนึ่งครั้งเพื่อให้ไฟล์ถูกแคช
- หลังแคชครบแล้ว สามารถเปิดแอปและบันทึกข้อมูลโดยไม่ต่ออินเทอร์เน็ตได้
- การอัปเดตเวอร์ชันใหม่ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อรับไฟล์ใหม่
- หากต้องการไม่ใช้อินเทอร์เน็ตแม้แต่ตอนติดตั้ง ควรทำเป็นแอป Android APK/iOS แบบติดตั้งในเครื่อง ไม่ใช่ PWA จาก GitHub Pages

ความปลอดภัย:
- PIN เป็นการล็อกหน้าจอแอป ไม่ใช่การเข้ารหัสฐานข้อมูล localStorage; ผู้ที่เข้าถึงอุปกรณ์/ข้อมูลเบราว์เซอร์ได้อาจเข้าถึงข้อมูลได้
- ไฟล์สำรอง JSON ไม่ได้เข้ารหัส ควรเก็บในที่ปลอดภัยและไม่ส่งต่อ
- การกู้คืนจะแทนที่ข้อมูลปัจจุบัน โปรดยืนยันและสำรองข้อมูลก่อนทำ
- ข้อมูลอยู่ในอุปกรณ์/เบราว์เซอร์นี้เท่านั้น ไม่ซิงก์ข้ามอุปกรณ์

ข้อจำกัดทางการแพทย์:
- การแจ้งเตือนเป็นการคัดกรองเบื้องต้น ไม่ใช่การวินิจฉัย
- การเตือนยาของเว็บทำงานได้เมื่อแอปเปิดอยู่เป็นหลัก ไม่รับประกันเมื่อปิดแอปหรือระบบพักเบื้องหลัง
